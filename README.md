# Ruang Seduh

Proyek portofolio: toko kopi online yang dibangun bertahap.

- Fase 0: situs statis dengan domain dan HTTPS (selesai)
- Fase 1: backend Node.js + Express dan database SQLite
- Fase 2: pesanan
- Fase 3: halaman admin
- Fase 4: deploy sebagai service
- Fase 5: dokumentasi dan tes

Demo: https://ruangseduh.cloud
